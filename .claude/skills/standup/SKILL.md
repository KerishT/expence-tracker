## Цель

Сформировать понятный и детальный отчёт о работе за вчерашний день — для озвучивания на стендапе.

## Алгоритм

1. `date` — определить вчерашнюю дату (формат `YYYY-MM-DD`)
2. `git log` — получить коммиты за вчера от текущего пользователя:
   ```
   git log --after="<вчера> 00:00" --before="<сегодня> 00:00" \
     --author="$(git config user.name)" \
     --pretty=format:"%h %s%n%b" --all
   ```
3. Если коммитов нет — сообщить об этом явно
4. Сгруппировать коммиты по scope из conventional commits (backend / frontend / shared / config / прочее)
5. Для каждого коммита:
   - Определить тип изменения (feat / fix / refactor / docs / …)
   - Раскрыть суть изменения понятным языком (не просто заголовок коммита)
   - Если есть тело коммита — использовать его для деталей
6. Вывести итоговый отчёт в виде структурированного текста

## Формат вывода

```
📅 Стендап — <дата вчера>

🔧 Backend
  • <что сделано, человеческим языком>
  • ...

🖥️ Frontend
  • <что сделано, человеческим языком>
  • ...

📋 Итого: <N> коммит(ов)
```

Если коммитов не было:
```
📅 Стендап — <дата>

Вчера коммитов не было.
```

## Правила

- Язык отчёта — русский
- Раскрывать суть изменений, а не просто копировать заголовок коммита
- Не добавлять предположения о том, что не отражено в коммитах
- Группировать по scope, а не по хронологии
- Эмодзи в заголовках секций — обязательны для читаемости
